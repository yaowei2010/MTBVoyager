- Default supplementary annotation path changed from `data/sa` to
  `data/sa-mtb`.
- Docker Compose mounts `FASTVEP_SA_DIR` at `/data/sa`.
- `run-hg38.sh` uses `/data/${FASTVEP_SA_SUBDIR}`; the default subdirectory is
  `sa-mtb`.

  `data/quarantine/gnomad_exomes_v4.osa2.invalid-20261022`.

## Supplementary annotations

The runtime directory contains 55 valid `.osa2` archives representing eight
source types:

- AlphaMissense
- ClinVar
- dbNSFP 5.3.1a with MTB score fields
- gnomAD exomes v4.1 (chr1–22, X and Y)
- phyloP100way (chr1–22, X and Y)
- PrimateAI
- REVEL
- SpliceAI SNV and indel

SpliceAI indel was converted from a repair copy after removing the final
incomplete BGZF block from the locally available source. The original source
was retained. A fresh licensed Illumina BaseSpace download remains preferable
for archival use.

## Validation

`scripts/integration-test-sa.sh` ran successfully against eight positive
variants. One annotation run opened all 55 providers and observed all expected
JSON keys: `alphaMissense`, `clinvar`, `dbnsfp`, `gnomad`, `phylop`,
`primateAI`, `revel`, and `spliceAI`.

The checksum inventory is generated by `scripts/build-sa-checksums.sh` and
verified by `scripts/verify-hg38.sh`.
